# Stock-Market-EDA-Anomaly-Detection

## 🔍 Project Summary
Developed an end-to-end **Stock Market Exploratory Data Analysis (EDA) and Anomaly Detection system** using Python. The project simulates realistic stock market behavior and applies statistical techniques to identify unusual trading patterns.

Designed to demonstrate **data analysis, statistical modeling, and visualization skills** relevant for **Data Analyst, Data Scientist, and Financial Analyst roles**.

---

## 🧠 Key Skills Demonstrated
- Data Analysis & Cleaning
- Exploratory Data Analysis (EDA)
- Statistical Analysis (Z-Score, IQR)
- Time Series Analysis
- Financial Data Analytics
- Data Visualization
- Feature Engineering

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## ⚙️ Key Features

- Generated **5 years of synthetic stock data (1260 trading days)** simulating real-world market conditions
- Engineered financial indicators:
  - Moving Averages (20, 50, 200 days)
  - Bollinger Bands
  - Daily & Log Returns
  - Rolling Volatility
- Implemented **Anomaly Detection Algorithms**:
  - Z-Score Method
  - Interquartile Range (IQR)
- Built visual analytics:
  - Price trends with anomaly markers
  - Return distribution histogram
  - Correlation heatmap across multiple stocks
- Exported actionable insights into CSV reports

---

## 📊 Results & Impact
- Identified abnormal trading days using statistical thresholds
- Improved understanding of stock volatility patterns
- Provided insights into inter-stock relationships (RELIANCE, INFY, TCS)
- Built reusable pipeline for financial anomaly detection

---

## 📁 Output Artifacts
